How to replace a candidate

Edit its plain object in site/unruggabull-ii/music-roof.js. Each object declares tempo, key, patterns, order, loop point and stems. A and B patterns provide contrasting four-bar hooks. The heavy object uses the same notes with faster tempo and a saw. New candidates can be registered with UnrugSound.registerTrack(id, data).

For the actual game use #stage=roof&music=a, music=b or music=c. This page loads the exact same audio.js and track data, and stays outside site navigation.
